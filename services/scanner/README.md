# 定位测扫描计分系统 V3

V3 是当前唯一继续维护的本地 macOS 阅卷项目，继承 V2 已验证的扫描与人工修正流程。

## 版本边界

- V1：已投入使用的旧稳定版，禁止覆盖。
- V2：历史升级工程，自 V3 建立后只作留档。
- V3：当前开发、测试和发布主线。
- 最终 App 名称：`定位测扫描计分 V3.app`。
- V3 用户数据位于 `~/Library/Application Support/定位测扫描计分 V3/`，不与 V1/V2 共用名单、答案或输出。

## 当前成绩导出

- 直接接受现行“原始名单模板”；前三列固定为“学号、中英文名、姓名”。界面只使用考号、中文名、年级、分校、班级和笔试时间，但保留原表其他业务列供导出回填。
- 名单学号 `S + 5位数字` 在阅卷内部自动映射为答题卡的 `0 + 5位数字` 考号；导出和后续结果管理仍保留原始 S 学号。
- 名单模板的分校从九个完整分校名称中下拉选择；年级统一使用“一年级”至“九年级”，班级与笔试时间仅保留原始内容。
- 分数字段：12 个 Part 和全卷总分；不导出 `Listening Total`、`Written Total` 或分析维度。
- `成绩汇总` 保留原始名单的列与值，在后面追加答题卡文件、12 个 Part、总分与异常状态。
- 作答状态：区分正确、错误、空白和识别不明确。
- 复核规则：客观题的识别不明确与机器空白候选都必须人工确认；整 Part 无有效作答时保留批量确认入口。
- 手工修改保留原始识别值、最终生效值、修改依据、操作人和时间；复核进度随图片目录持久保存。
- 原图在 Mac“预览”修改保存后，可只重新识别当前一张，不需重扫整批。
- 修图入口会启动不恢复旧窗口的独立“预览”实例，避免其他已修改图片被一并打开。
- 名单外的六位考号不丢弃成绩；可在系统内补齐学生身份，未补齐时作为异常记录保留在表尾。
- 单一 Excel 文件包含 `成绩汇总`、`逐题明细` 和 `需复核名单` 三个 Sheet；只有复核完成的文件才能进入结果管理系统。

## 开发与发布

- 调试入口：`app/scan_ui.py`
- macOS 入口：`app/desktop_launcher.py`
- PyInstaller 配置：`定位测扫描计分 V3.spec`
- V3 默认本地端口：`8503`，可用 `DINGWEICE_PORT` 覆盖。
