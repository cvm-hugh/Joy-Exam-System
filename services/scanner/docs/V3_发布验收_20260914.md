- 12 个 Part 和全卷总分；不导出分析维度。
- 取消 `Listening Total` 和 `Written Total`。

## 发布注意

项目所在目录由 macOS File Provider 管理，会自动向目录内的 `.app` 根节点附加 FinderInfo，从而影响严格签名校验。因此正式交付物是在干净临时目录中签名、校验后生成的 ZIP；使用时应先解压 ZIP，不要将 `dist/` 内的工作副本作为对外发布包。
