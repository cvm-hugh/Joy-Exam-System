## 页面与导出验证

- 后台预览和 PDF 使用同一套 390 × 844 页面组件。
- 报告固定 9 页，页面只使用边框、不使用投影。
- 实际浏览器检查六个评价页的页面与卡片 `scrollHeight` 均未超过 `clientHeight`。
- 阅读理解长文页采用专用微调：建议正文左右各增加约半个字宽度，并略收紧分隔区纵向留白；字体和字号不变。
- 导出前仍保留程序化溢出检查，任何页面超出标准尺寸即中止该学生导出并给出明确提示。

## GitHub 备份边界

GitHub 只备份源码、数据库结构、测试、脚本和文档。以下内容由 `.gitignore` 排除：

- `.dev.vars`、`.local/`、`.wrangler/` 和管理员凭证。
- 本机真实学生数据库、成绩导入文件和导出报告。
- `node_modules/`、构建缓存和生成产物。

因此 GitHub 可恢复当前程序版本，但不能恢复真实学生批次；业务数据需要单独的加密备份与恢复流程。
