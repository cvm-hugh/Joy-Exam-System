# 系数计算与等级判定规则

> 状态：已确认，作为当前试卷模板与家长端结果页的统一计算规则。

**得分系数 = 维度得分 ÷ 维度总分。**

系统计算、等级判断和精修班口试资格判断使用完整原始系数；页面展示时保留小数点后1位，采用直接截断，不进行四舍五入。

## 等级阈值

| 等级 | 原始系数区间 |
| --- | --- |
| 卓越 | [0.8, 1] |
| 优秀 | [0.6, 0.8) |
| 良好 | [0.4, 0.6) |
| 待加强 | [0, 0.4) |

## 实施说明

- 完整原始系数用于匹配等级、评价内容、学习建议与下一步建议。
- 页面与六维雷达图仅显示截断后的系数；该展示值不反向参与等级判定。
- 页面低分保护：听力、词汇、语法、交际、阅读最低显示0.3；写作最低可显示0.0。保护值不参与等级或资格判断。
- “导出六维得分系数”使用真实系数，直接向下截断至2位小数，不使用页面0.3低分保护。
- 例如原始系数为 `0.79`：页面显示 `0.7`，等级仍按 `0.79` 判为“优秀”。
- 例如原始系数为 `0.80`：页面显示 `0.8`，等级判为“卓越”。
