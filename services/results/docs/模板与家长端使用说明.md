# 模板与家长端使用说明

## 导航与职责

- 教学支撑：试卷模板。先选择一套卷，再在卷内进入“套卷总览”“题型与满分”“系数阈值”“评价管理”。
- 行政服务：成绩导入、学生预览、配置与发布。

这是工作流程分组，尚未新增不同部门的账号权限系统。评价管理不再显示Part计算面板或阈值快捷入口。

## 首次建立配套试卷

1. 尚未保存任何套卷时，教学支撑→试卷模板→“建立首套试卷模板”。此首次初始化使用当前考试配置，不是复制已选模板。
2. 输入名称。这会复制当前考试完整教学配置，不修改任何学生、考试结果或发布状态。
3. 按需要检查题型、满分、六维关联、等级分档和24套评价。已有配置直接保留，无需重填。
4. 点击“保存本套卷”。此后在模板库选中它即自动载入，不再设置单独的载入按钮。切换或清空选择前如有未保存修改，会先提醒；取消则保留原选择和草稿。

进入模板库时，默认选中并载入已保存的“学业水平统测｜英语2608”（也兼容名称“学业水平统测｜2608”）。找不到这套模板时保持未选择；手动切换、清空或开始新建后不会自动跳回。默认载入不改变当前考试和学生成绩。

默认显示查看状态；点击“进入编辑”才展开编辑表单。收起编辑或切换卷内栏目会保留本套卷草稿；未保存输入刷新后会丢失，离开套卷有提醒。

## 保存默认版本与另存

“从当前试卷模板复制新建”：先在下拉框选择一套试卷，自动载入后点击此按钮。复制的是当前载入模板的已保存版本，不是当前考试配置；如有未保存修改，先提醒确认。副本自动进入编辑状态，可修改名称和内容，点击保存后新增独立模板，原模板不变。没有载入模板时此按钮禁用。

“保存本套卷”把题型、满分、维度、系数阈值、评语、图片引用和段落标题作为一套配套内容一起持久保存，更新这套卷的默认版本。不是每次输入一个字就自动保存。

更名：套卷总览→编辑名称→修改名称→保存本套卷。复制新卷：套卷总览→编辑名称 / 另存套卷→另存为另一套试卷→填写新名称。新卷独立保存，原卷保留；同名不覆盖。

保存教学模板不追改已经导入的学生结果，即使当前查询开放也可维护下一次要用的模板。学生原始成绩不放入模板。

## 卷内题型与系数阈值

“题型与满分”维护Part名称、满分上限及六个评价维度的名称和Part关联。维度标识与顺序固定，名称可改。一个Part可参与多个维度，总分只计算一次。

“系数阈值”只管理等级分档。当前确认规则：

| 等级   | 原始系数区间     |
| ------ | ---------------- |
| 卓越   | 0.8 ≤ 系数 ≤ 1   |
| 优秀   | 0.6 ≤ 系数 < 0.8 |
| 良好   | 0.4 ≤ 系数 < 0.6 |
| 待加强 | 0 ≤ 系数 < 0.4   |

上限在上、下限在下；下限包含，最高上限1包含，其余上限不包含。修改公共边界会联动相邻等级。保存时检查0～1覆盖完整且无重叠；完整原始系数用于等级判断，页面展示时直接截断至小数点后1位，不进行四舍五入。

## 评价管理与Excel导入

1. 载入套卷→评价管理→进入编辑。
2. 可逐维编辑四个等级的评价标题、三段正文、占位标记和评价图片，或打开“Excel批量导入评价”。
3. 下载空白上传模板。固定5列：维度、等级、能力描述、学习建议、下一步建议；每行都填维度与等级，24行不合并、不用分节表头、不含公式，每段最多2000字。
4. 选择Excel→校验评价文件→核对24套预览和名称映射→载入本套卷评价。
5. 点击“保存本套卷”，才持久保存为该套卷的默认评价。校验成功本身不会保存。

Excel导出和校验使用当前教学套卷的维度，不借用当前考试的维度。Excel仅替换三段正文及段落标题，保留本套卷原有评价标题和图片。正式内容需要人工核对并取消占位标记，之后可勾选已核对全部24套评价。

兼容“良→良好”“词汇应用→词汇运用”“语言运用→语法运用”“情景交际→交际能力”；映射会提示。正文中的<br>转换为换行，不擅自改写内容。

## 旧版模板与删除

旧版分析、阈值、评价模板原样保留。在对应卷内栏目进入编辑后，展开“复用 / 管理旧版模板”，选择后复制到本套卷。复制前核对六维名称与顺序；复制后还要保存本套卷。旧分析模板仅复制题型、满分、维度关联，不带入旧分档；旧评价只复制评价内容，不改计算规则。旧模板后续不会自动与套卷同步。

模板库可删除指定套卷；旧版复用区可删除指定旧模板。均有页面内二次确认与版本检查。删除只移除指定模板记录，不删除当前考试、学生、图片或已复制到其他套卷的内容。删除后没有一键恢复入口，请先另存需要的副本。删除失败会显示错误，仍可选择其他模板。无需删除任何程序文件。

## 行政选择套卷与导入

1. 成绩导入→选择已保存的配套试卷→下载对应Excel/CSV成绩表。
2. 填写并上传成绩，确认整批替换。
3. 全部校验成功后，一次启用同一套卷的题型、满分、维度、等级分档和评价，以及本批学生数据；任何一步失败都保留原状态。
4. 学生预览检查结果，再到配置与发布开放查询。正式上线仍需环境和人工验收。

## 首页、学生分页与入口预览

工作台仅展示当前查询状态、当前批次使用的试卷模板和学生人数。模板名称来自导入时保存的来源快照，不随模板库的选择改变；没有关联来源的旧批次显示“当前考试配置（未关联套卷）”。

成绩导入及学生预览中的当前批次名单默认每页10人，可在表格下方选择10、20、30、40或50人；更换每页人数后回到第1页。

“配置与发布”中的“结果查询演示预览”和“正式开放小程序查询”左侧按钮仅切换入口效果预览，右侧开关控制实际查询状态。开关显示“已开放／已关闭”，两种模式互斥；正式环境、发布校验与确认仍保留。

下方按入口页、查询内容页、封底页排列，每页左侧编辑、右侧预览。编辑默认收起；展开后可改文字与图片，预览同步显示草稿。点击“保存页面配置”保存当前所有页面修改，查询开放期间不可修改。入口预览固定提供“开放状态预览”和“关闭状态预览”，不跟随实际开关自动合并；品牌logo位置留空。内容页采用非真实学生的版式示例，不写入名单；六维评语仍由当前批次配套配置提供。

封底底图与中心二维码分别上传，二维码选填；不上传时不显示二维码区域。中心说明及底部文字也可编辑。所有封底素材和文字都为空时，家长端不显示封底；旧内容页尾图保留，不自动迁移为封底。

图片制作标准（建议尺寸，不强制裁剪）：内容页顶部／底部图片750×300像素；封底底图750×1334像素；二维码480×480像素（保留白边）；评价图片750×1000像素。均支持PNG、JPEG或WebP，单图不超过2MB。封底底图居中铺满，比例不同时边缘可能裁切；二维码和内容图片等比完整显示。

“沿用当前考试的整套配置快照”保留当前考试已经使用的全部配置，不跟随模板更新。切换到新模板后，需要重新导入对应成绩才能使用新版本。旧批结果不会被模板编辑或删除悄悄改变。

成绩导入页默认选择“学业水平统测｜英语2608”。进入页面及选择模板时自动取得可用模板，选中即采用，无需刷新按钮；Excel与CSV下载位于右侧。如果套卷更新，旧的待导入文件会清除，需重新下载并选取文件；后端仍校验模板版本，防止并发修改造成混搭。

### 零星补录

“成绩导入 → 03 · 零星补录学生成绩 → 补录一名学生”：填写中文姓名、考号和各Part分数，点击“校验并预览”，核对自动合计总分及六维等级，再确认新增。只追加该学生，不替换名单、不覆盖重复考号。

补录使用当前批次已应用的试卷配置，不使用上方另行选择的导入模板。每个Part必填，总分由服务端计算，共享Part只计一次。先关闭查询，保留考号前导零；当前批次或规则已改变会拒绝旧草稿。保存成功后可继续录入下一名。不支持在补录入口修改已有学生成绩；无首批数据时请先整批导入。

成绩替换、当前考试设置和发布期间的配置修改仍受查询开关保护；教学模板维护不自动关闭查询，也不改变家长当前看到的结果。

## 家长看到的小程序怎么搭建

小程序不是后台网页的缩小版，也不是重新做一套计算系统。当前已有原生微信小程序源码，共用后台接口：

- 查询页：中文姓名、考号、查询按钮、失败和未开放提示。
- 结果页：考试信息、六维雷达图、六个维度的等级与三段评价。无Part成绩、总分、排名或其他学生信息。
- 雷达图：白底、灰色六边形网格、红色折线、周围显示维度名及一位小数系数；取消独立六项百分比列表。

### 现在：电脑预览

保持本地后台服务运行，用已安装的微信开发者工具导入项目的`miniprogram`目录。当前为游客AppID，接口地址是本机localhost，仅用于电脑开发工具调试。详细操作见`miniprogram/README.md`。不需要再上传一遍成绩或把管理员口令放进小程序。

### 账号到位：手机体验

提供真实AppID、开发者和体验成员权限，确定使用旧云环境还是独立测试服务；配置手机可访问的测试接口后，生成预览/体验版本，在微信中核对真实排版与查询流程。手机上的localhost指手机自己，无法直接访问电脑的本地后台。若沿用云开发，需要适配对应调用/存储方案。

### 最后：正式上线

补齐视觉素材、正式文案与隐私资料，完成iOS/Android真机联调、边界学生人工复核、性能和安全检查后，再提交平台审核和发布。后台开放查询与微信小程序审核发布是不同动作。

本地源码、接口检查或WXML/WXSS编译通过均不代表手机体验版已完成。当前未上传微信、未发布到公网。
