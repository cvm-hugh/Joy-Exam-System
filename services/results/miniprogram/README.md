# 微信小程序 · 本地基础版

这是原生微信小程序源码，不是H5包装。包含查询页、结果页与Canvas 2D六维雷达图。正式AppID未提供，当前使用游客AppID `touristappid`。

## 开发者工具中试用

1. 保持父目录的`npm run dev`运行；已初始化的项目无需再次setup。后台已导入名单时不必重复导入，查询需处于演示开放或正式开放状态。
2. 使用微信开发者工具导入本目录；有真实AppID后替换`project.config.json`中的游客AppID。
3. `config.js`默认访问 `http://localhost:3000/api`。仅在本机调试时，在开发者工具本地设置中临时关闭合法域名/HTTPS校验，不把这一设置带入正式发布。
4. 使用当前批次中有权测试的学生姓名和考号查询；不要在截图或日志暴露真实学生信息。不需要把后台口令放进小程序。
5. 试用结束在后台关闭查询。

真实手机中的localhost指手机本身，无法直接连到电脑服务。真机联调需在AppID与云资源到位后配置可访问的HTTPS测试服务及合法域名，不能把开发者工具编译通过当成手机端已经跑通。

## 发布前

- 配置真实AppID、服务器域名/云环境及开发者、体验成员权限。
- 将`config.js`改为 `environment: 'production'` 和正确的HTTPS API地址。
- 恢复并验证域名校验，核实图片下载域名。
- 小程序运行在release环境但仍是local配置时，查询会被阻止。
- 完成隐私说明、业务内容、微信手机真机测试和平台审核。

## 隐私与状态

姓名/考号使用POST请求；查询结果只保留在页面/应用内存，不落本地持久缓存。切到后台会清理结果，回来需要重新查询。结果页打开时再次核对发布状态与版本，避免关闭或换批后沿用旧结果。不提供成绩分享功能。已经显示或被用户截图的信息无法由关闭开关追回。
