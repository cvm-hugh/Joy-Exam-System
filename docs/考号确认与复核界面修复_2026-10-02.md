# 考号确认与复核界面修复

在独立主线 `05a680c` 的基础上完成。所有改动位于本项目，未修改旧独立软件。

## 页面变化

- 每张待复核考卷只展示一次基础信息和一次“修改图片并重新识别”按钮。
- 考号区域在左，整张答题卡在右；两者来自同一份原始图片。
- “考号核对”和“答题内容核对”使用同一级标题；考号尚未确认时，也能查看需要复核的答题内容。
- 确认考号或补全身份后，当前考卷保留在复核区，显示保存结果。只有点击“完成并收起本张”才将已完成考卷收起。
- 删除处理结果下的“修改已完成记录”及其整卷修改面板。现有单题修正、教师登分区核对和图片重新识别入口继续按原始图片处理；已有历史修正数据与审计记录保留。

## 考号规则

旧规则已迁移，但先前只有名单表头为“学号”时才将 `S10086` 转为 `010086`，人工确认输入也仅接受六位数字。失败提示位于复核区上方，用户点击后容易看不到原因。

现在名单读取与人工确认共用同一转换函数。所有受支持的考号表头，包括“学号”“考号”“Exam ID”“准考证号”，均将 S 或 s 加五位数字转换为 0 加五位数字；短数字仍按原规则补足六位。转换后的重复考号会被拒绝。

- 输入 `S10086` 或 `010086` 都按内部考号 `010086` 匹配。
- 名单内学生的成绩汇总保留原始名单学号 `S10086`，原始 Excel 单元格不改写。
- 原始学号也保存到扫描记录；原名单副本缺失时，已知原始学号仍可用于旧格式汇总导出。
- 不在当前名单中的考号显示就地错误，明确提示核对当前名单或补全后补学生信息。五项身份信息不齐时，不确认身份、不写入修正审计。
- 后补学生只写入本批复核记录；填写 S 学号时，内部按数字考号处理，汇总导出保留该 S 学号。
- 原图重新识别时清空该卷的旧身份输入与提示，避免复用上一轮的确认值。

这些变化补齐已发现的输入和表头路径。不能仅凭 S 前缀断定所有历史确认失败都来自同一个原因；名单缺人和本次名单选择不一致仍会按实际名单明确提示。
