# Windows 启动依赖修复

版本：2.1.0-beta.2。执行日期：2026-10-07。

## 日志结论

实际 Windows 日志中，阅卷服务启动，结果服务监听端口后在加载接口时重复报 `Cannot find module 'rimraf'`，桌面因健康接口未就绪而启动超时。提供的日志内该错误重复 515 次。

## 修改

- Node 构建将 ExcelJS 保持为完整的外部运行包，避免其 CommonJS 间接依赖遗漏于外部依赖清单。
- 从本项目锁定的安装树复制完整运行依赖，保留嵌套目录和不同版本的选择；缺失必需依赖时构建失败。
- 生成内部运行依赖清单，静态核对入口依赖、依赖版本和 `ExcelJS → unzipper → fstream → rimraf` 链；Windows 暂存文件和最终 ZIP 再次核对。
- 稳定 V2.0、已安装 Mac App、实际考试数据及业务接口规则保持原样。

本次修复针对日志已确认的打包缺失。构建和文件检查不等于实际 Windows 功能验收；需要接收方使用新包确认启动及后续工作流程。本次不新增或运行功能测试。
