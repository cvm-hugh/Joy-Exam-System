# 参考信息与导出补充提醒

日期：2026-10-03。只在统一项目“佳音考试管理”中维护。

## 规则

- 年级选填。初一、初二、初三统一为七年级、八年级、九年级。
- 空白、`/`、`／`、`-`、`—`、未知、不详、不清楚、待补充、未填写、N/A 视为未提供；管理名单显示待补充。
- 无法对应一年级至九年级的其他写法保留原值，提醒核对，不阻断导入或导出。
- 阅卷临时补录允许年级留空；姓名、分校、班级和笔试时间沿用身份补录要求。
- 考号、身份和成绩校验沿用原规则；导入仍按整批事务处理。

## 信息补充和导出

- 约定检查字段为分校名称、班级名称、笔试时间、年级。备注等允许为空的其他字段不触发提示。
- 提醒明确列出考号、姓名、字段和当前内容；未填写显示“该信息需要填充”。
- 结果管理在导出所选学生或全部学生前检查当前版本，只检查本次导出范围。
- 提供“返回补充”和“继续导出”。名单新增信息补充入口，保存当前分校、班级、笔试时间及年级；考号、姓名、分数、原始导入内容保持原值。
- 信息补充仅在关闭查询时保存；版本、批次和身份检查防止跨批次或过期覆盖。
- 年级、班级、笔试时间缺失不会阻断家长报告导出；报告版式和成绩算法沿用原规则。
- Excel 的 Sheet1 使用当前信息，保留既有教务名单列与成绩、六维得分系数。
- Excel 附有“信息待补充”清单；“原始名单信息”完整保留各导入格式的已读取原始字段，也包括 Sheet1 中未列出的额外字段和原始年级写法。
- 阅卷 Excel 备份同样附有“信息待补充”清单，原名单与人工补录内容继续随成绩汇总保留。
- 既有学生数据不自动改写；原始内容的保留规则适用于本次及之后导入，系统不会凭空恢复历史未保存的字段。
