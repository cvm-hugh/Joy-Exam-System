# 佳音考试管理 V2.0

- 版本号：`2.0.0`，界面标识：`V2.0`。
- 发布日期：2026-10-04。
- 唯一维护源码：本目录及 `services/scanner`、`services/results`。
- 本次发布包含此前已使用的审核定位、人工结果保留、参考信息提示、教学备份和运营存档导出，以及学生预览首尾折叠与横竖排列选择。
- 本次整理集中阅卷状态操作，拆分请求和导出辅助代码，预计算导出维度配置，并加入 Python 源码静态检查。

## 本机 App

App 构建仍为本机维护版本：依赖当前项目路径、项目独立依赖和本机 Python/Node 解释器。更新应用程序包不会覆盖实际考试数据。其他 Mac 的完整运行环境封装、签名、公证和 Windows 桌面入口尚未完成。

- 当前主线的 Git 提交和 `v2.0.0` 标签。

## 验证范围

本轮执行静态检查、构建与文件一致性检查；未运行自动化测试或启动 App 操作验证。源码结构比较覆盖本次搬移的阅卷操作与直接 Streamlit 渲染调用。
