# 教学备份与运营存档导出

## 界面与文件内容

三个按钮按以下顺序排列，沿用既有的学生选择范围、版本检查与忙碌状态：

1. 导出全部学生 PDF（选中学生后沿用所选学生 PDF 文案）。
2. 导出六维系数名单（运营存档）。
3. 导出详细得分名单（教学备份）。

教学备份沿用原详细导出：Sheet1 包含名单信息、精修笔试通过、六维系数、各 Part 得分、考试总分及维度总得分；附有 Sheet2 计算说明、“信息待补充”和“原始名单信息”。

运营存档只生成一个 Sheet1，保留名单信息、精修笔试通过情况和六维得分系数，截止到“写作能力得分系数”列。不写入 Part 分数、总分、维度总得分，也不生成说明或信息附表。

系数计算沿用当前规则：维度实际得分除以对应满分，向下截断保留两位小数，不使用页面预览的低分保护。精修笔试通过情况沿用当前考试已应用套卷的资格判断结果；资格结果默认计算和显示，不再提供单独的启用开关。

## 默认文件名

- 教学备份：原文件名去掉扩展名后加 `详细得分.xlsx`。
- 运营存档：原文件名去掉扩展名后加 `六维系数.xlsx`。
- 阅卷导入名单时记录用户上传的原文件名，随内部成绩交接传入结果管理；直接导入结果管理时记录上传的成绩文件名。
- 文件名与成绩批次在同一事务中保存；旧数据库只增补可空字段，既有成绩与计分配置不改写。
- 原文件名未保存的历史批次，可在导出区补填。输入按批次在本机记住；未填写时暂用考试名称，避免使用内部临时文件名。
- 文件名移除路径、处理不支持的字符并限制长度；内容选择和导出学生范围不受文件名影响。

### 原名单命名补充

用户确认默认文件名应采用阅卷时导入的学生名单文件名。例如原名单 `学业水平测试统计名单-0930KDTKL.xlsx` 对应：

- 运营存档：`学业水平测试统计名单-0930KDTKL六维系数.xlsx`。
- 教学备份：`学业水平测试统计名单-0930KDTKL详细得分.xlsx`。

末尾已有六维系数或详细得分等导出后缀时，先去掉再添加本次后缀，避免重复累加。

这批旧名单未保存原文件名；已核对用户指定文件与阅卷端的 `roster_source.xlsx` 字节一致。补记原名单文件名到阅卷文件名记录和当前结果批次的文件名字段，不重新导入学生或成绩。更新时校验名单摘要、批次与版本，只修改文件名元信息。

已完成上述旧批次文件名补记。事务内及更新后的学生、分数、计分配置和批次版本摘要一致；其他运行文件未改动，仅文件名记录及相应数据库存储文件发生预期变化。源码静态检查、`npm run check` 和 macOS App 构建及签名校验通过。未运行自动化测试或进行 Excel 导出界面复测。
