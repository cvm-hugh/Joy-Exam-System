# 固定界面缩放入口

## 用户需求

阅卷页面内容很长，标题下方的缩放按钮在向下滚动后不易找到。将它放到右上角 Deploy 所在工具栏旁，滚动时持续可见。

## 实现

- 保留原生缩放弹层和 `ui_zoom` 状态键，提供 75%、85%、100%、110% 四种比例。
- 缩放按钮使用独立、固定定位的容器，位于顶部工具栏左侧。
- 读取当前顶部工具栏的位置及可见控件尺寸；窗口调整和运行状态变化时更新按钮位置，避开 Deploy、菜单、运行状态和 Stop 控件。
- 正文放入独立工作台容器，缩放只作用于该容器。缩放入口和顶部工具栏不随正文比例改变。
- 位置辅助脚本只读取工具栏尺寸和写入位置 CSS 变量，不移动原生控件节点。重新载入时清理旧监听器。
- 人工审核、逐题展开、完成收起和保存逻辑保持原有调用；审核组件仍在局部刷新区域中。
