# 固定界面缩放入口

## 用户需求

阅卷页面内容很长，标题下方的缩放按钮在向下滚动后不易找到。将它放到右上角 Deploy 所在工具栏旁，滚动时持续可见。

## 实现

- 保留原生缩放弹层和 `ui_zoom` 状态键，提供 75%、85%、100%、110% 四种比例。
- 缩放按钮使用独立、固定定位的容器，位于顶部工具栏左侧。
- 读取当前顶部工具栏的位置及可见控件尺寸；窗口调整和运行状态变化时更新按钮位置，避开 Deploy、菜单、运行状态和 Stop 控件。
- 正文放入独立工作台容器，缩放只作用于该容器。缩放入口和顶部工具栏不随正文比例改变。
- 位置辅助脚本只读取工具栏尺寸和写入位置 CSS 变量，不移动原生控件节点。重新载入时清理旧监听器。
- 人工审核、逐题展开、完成收起和保存逻辑保持原有调用；审核组件仍在局部刷新区域中。

## 容器复用异常修复

用户确认缩放入口已生效，但已有识别结果时，审核区域报错 `TypeError: 'NoneType' object does not support the context manager protocol`。

原因是将 `with st.container(...) as workbench` 的上下文进入返回值当作容器复用。本项目 Streamlit 的 `DeltaGenerator.__enter__()` 返回 `None`，因此下方 `with workbench` 失败。

改为先通过 `workbench = st.container(...)` 保存容器，再用 `with workbench` 分别绘制扫描区域和审核区域。容器键、缩放样式、保存及复核逻辑不变。
