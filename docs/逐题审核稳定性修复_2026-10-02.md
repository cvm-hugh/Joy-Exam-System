# 逐题审核稳定性修复

本次在“佳音考试管理”的独立源码基线 `f4042be` 上进行，未回写旧独立项目。

## 复现与原因

使用实际 `scan_ui.py` 页面、虚构名单和八道待复核题目，在隔离的临时运行目录中复现。旧实现保存一题后，该题表单向下偏移 144 像素；浏览器窗口的 `scrollY` 始终为 0，实际滚动发生在 Streamlit 内部 `stMain` 容器。

旧脚本还假定表单 key 会生成可定位的 CSS 类，并使用 iframe 的自动内容测量。实际浏览器中未捕获到有效锚点，自动测量报出 MutationObserver 异常。

## 改动

- 将复核、成绩汇总及导出控件一起放入局部更新区；保存单题时不再重跑上方考试设置与照片目录区域。
- 题目单选框和保存按钮使用固定 key，保存前后保持同一控件身份。
- 重新识别单张图片、批量重扫或开始新一批时清空旧选项键，避免上一轮人工选择影响新的识别结果。
- 题目结果提示占用固定的一行，成功提示改用 toast，减少页面高度变化。
- 每题使用带 key 的独立容器作为明确锚点；保存时记录其视口位置，按照当前偏移增量调整内部滚动容器，支持多次重新排版。
- 隐藏 iframe 使用固定尺寸及完整 HTML 文档，移除自动内容测量的报错。
- 滚轮、触摸或其他主动操作会释放位置锁定；支持鼠标保存、重新保存和键盘提交。

## 验证

浏览器回归入口为 `npm run test:review-ui`；其代码与锁定的 Playwright 开发依赖均在本项目维护和安装，使用本机 Chrome 或 `JOY_BROWSER_EXECUTABLE` 指定的 Chromium 浏览器。

| 显示比例 | 修复后保存位置最大偏移 |
| --- | --- |
| 75% | 0 像素 |
| 100% | 0 像素 |
| 110% | 0 像素 |

三个场景均通过其他题目未提交选项保留、重复修正、键盘提交、局部更新次数、主动滚动释放、八题完成后的导出可用状态验证。关闭浏览器后检查临时持久化文件，确认十条审计记录、修正前后值、操作人、最终选项和已完成状态。

另在关闭浏览器默认滚动锚定后，主动插入及移除 120 像素高的临时元素，确认页面高度变化时位置仍能恢复，重复调整不累积误差。验证全程无浏览器异常。

最终 `npm run check`、30 项阅卷测试、118 项结果管理测试、三个浏览器回归场景以及 macOS 编译、本地签名检查均通过。实际 `runtime/` 文件摘要与独立化前一致。
