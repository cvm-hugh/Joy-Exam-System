# 阅卷到结果管理：交接约定 v1

阅卷系统生成的成绩工作簿仍是内部数据校验边界，但只在临时目录生成，并由本机内部通道自动提交；用户不需要另存或重新上传。

## 输入与输出

- 阅卷端完成图片识别、人工核验与成绩计算后，生成完整成绩工作簿。
- 结果管理端继续使用现有严格导入器读取该工作簿，避免出现两套计分或校验规则。
- 成绩汇总保留原始名单全部列，并从既定成绩起始列写入 Part 分数和总分。
- 逐题明细保留原始识别值、人工修正值、操作人与修正时间。
- 待核查页只保留人工修正后仍无法解决的问题，不重复已完成的人工复核结论。

## 自动交接的安全条件

“完成阅卷并进入结果管理”必须同时满足：

1. 阅卷批次已经完成；
2. 不存在尚未确认的图片识别项；
3. 名单外考号已明确保留并标记异常；
4. 工作簿通过结果管理端现有导入校验；
5. 导入前保留一份不可覆盖的交接文件及校验结果。

未满足条件时只允许另存备份和查看错误，不自动写入结果数据。内部接口只监听本机，并使用每次启动随机生成的桌面令牌；结果管理页面使用同一令牌建立临时管理员会话。
